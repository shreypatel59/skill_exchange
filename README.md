# Skill Exchange

## Overview

Skill Exchange is a web-based platform that allows users to share, learn, and exchange skills with others. The platform helps users connect based on their interests and expertise, creating a collaborative learning environment.

## Features

* User Registration and Login
* User Profile Management
* Skill Listing and Management
* Search Skills
* Responsive User Interface
* Database Integration

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript

## Installation

1. Download or clone the repository.
2. Place the project folder inside the XAMPP htdocs directory.
3. Import the SQL database into phpMyAdmin.
4. Start Apache and MySQL from XAMPP.
5. Open the project in your browser.
